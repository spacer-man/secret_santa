# 🎄 Secret Santa Bot project
Secret Santa - мой новогодний проект, со следующей целью.
**Target:** Принести ощущение праздника большому количеству людей. ✨
**Second Target:** Заработать на этом денег. 💰
**Target auditory:** Подростки и взрослые: 14 - 45 лет. 👨‍👩‍👧‍👦

## 🤖 Core bot idea
**Бот** - *игра в тайного санту* между всеми пользователями.
**Каждый** пользователь получит поздравление от другого **анонимного случайного пользователя** ровно в `00:00` по его времени. ⏰
**Каждый пользователь** до наступления Нового Года в последнем часовом поясе может оставить поздравление, для которого случайным образом будет выбран получатель.
На каждое поздравление можно будет *анонимно* ответить / отреагировать (написать ответ / отправить реакцию). 💬
При нехватке поздравлений, поздравления будут отправляться *нескольким пользователям*.
При отсутствии поздравлений совсем, всем будут отправляться *заранее заготовленные поздравления*.
В таком случае все ответы на поздравления будут отправляться *мне* (создателю бота).

## ⚠️ Important details
### 📜 User agreement (!!!)
У бота должно быть пользовательское соглашение.
В нём обязательно должны быть отражены пункты о:
- использовании пользовательских данных;
- защите авторского права.

### 🎁 Wishing (пожелание, т.е. новогоднее поздравление)
Поздравление может быть:
- текстом;
- голосовым(аудио);
- картинкой(-ами);
- видео.
**Минимум** - что-либо из этого: текст, голосовое(аудио), картинка(-и), видео.
**Максимум** - всё: и текст, и картинка(-и), и видео / голосовое(аудио).

### 🔒 Anonymity and security
- Каждое поздравление будет проходить модерацию (предположительно с помощью LLM из Open Router). 🤖
- При обнаружении неприемлемого контента пользователь сможет пожаловаться, и ему будет прислано другое поздравление. ⚠️
- Ограничение на количество поздравлений в день, чтобы избежать флуда. ⏳
- Ограничение на общее количество поздравлений от одного пользователя.

### 📜 Copyright check
Каждое поздравление должно проходить проверку авторских прав (пока предположительно вручную).

## 💡 Additional ideas
### 📜 New Year's wish
Пользователь может оставить своё личное желание на предстоящий год и послание себе на следующий Новый год.
Бот пришлёт эту информацию ровно через год. 📅

### ✨ Wishing personalization
Пользователь может указать свои предпочтения по поздравлению (например, "люблю мемы" или "предпочитаю короткие поздравления").
Эти данные будут использоваться только для подбора поздравлений и не будут видны другим пользователям. 🔍

### 🎮 Activities for users
1) **Конкурс на лучшее поздравление:**
   - Пользователи оценивают полученные поздравления по 5- или 10-балльной шкале. ⭐
   - Автор поздравления с наивысшей оценкой получает приз (например, месяц подписки у партнёра). 🎁
   *(!!! Для корректности все поздравления должны отправляться примерно равному количеству пользователей.)*

2) **Отсчёт до Нового года:**
   - Для всех — в днях; 📅
   - Для каждого — точно (со временем). ⏰

3) **Бесплатная лотерея за участие в викторинах:**
   - Правильно ответившие на все вопросы получают шанс выиграть подарок. 🎉
   - Участники могут получить новое оформление в боте. 🎨

4) **Конкурс "Лучший новогодний мем":**
   - Оценивание мемов (механика не определена). 😂
   - Приз (не определён). 🏆

### 📚 Interesting facts
Выкладывать интересный контент в телеграм-канал бота:
- Традиции разных народов, связанные с Новым годом; 🌎
